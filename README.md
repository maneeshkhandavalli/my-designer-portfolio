# Maneesh Khandavalli — Portfolio

Single-page, animation-heavy editorial portfolio.
Vite · React 19 · TypeScript (strict) · Tailwind CSS v4 · GSAP + ScrollTrigger · Lenis · three.js / React Three Fiber / Drei.

```bash
npm run dev      # dev server
npm run build    # type-check + production build
npm run lint     # oxlint
```

## Conventions

- **Imports** use the `@/` alias for `src/`.
- **Sections**: order, anchor ids and nav labels live in `src/lib/sections.ts`. Every section renders through `components/layout/Section.tsx` (id is type-checked against that list). `App.tsx` only composes sections.
- **GSAP**: always import `gsap`, `ScrollTrigger`, `useGSAP` from `@/lib/gsap` (plugins registered once there). Use `useGSAP` for scoped cleanup and `gsap.matchMedia()` with `MOTION_QUERIES` for reduced-motion / breakpoints.
- **Scroll reveals** (`lib/reveal.ts`, `hooks/useReveal`): the shared motion language for every section. Mark elements `data-reveal="lines|rise|fade|clip-x|clip-y|rule"` (optional `data-reveal-delay`, and a `data-reveal-zoom` child for clips) and call `useReveal(sectionRef)`. Each element reveals as it enters, reverses as it leaves and replays on return (toggleActions `play reverse play reverse`); reduced motion shows everything as is. Inside a pinned horizontal track call `createReveals(el, { containerAnimation: trackTween })`: elements already in view while the track is at rest reveal on the vertical approach and leave at the pin's release; the rest follow the track. Transforms, opacity and clip-path only — no filters.
- **Smooth scroll**: Lenis is global (`components/effects/SmoothScroll`), driven by GSAP's ticker and synced to ScrollTrigger. Get the instance with `useLenis()` from `lenis/react`; use `useScrollToSection()` for in-page navigation.
- **WebGL**: wrap scenes in `components/effects/WebGLCanvas` and lazy-load them (`React.lazy`) so three.js stays out of the initial bundle.
- **Design tokens** (`src/styles/globals.css`, `@theme`): `background` #050505, `foreground` #F5F5F2, `accent` #C72020, `ink` #0B0A09 (light-mode type), `canvas` #F3F1EC (Hero background), `panel-muted`, `muted`, `line`, `surface`, `chrome` (navbar/frame ink, follows the page tone) → utilities like `bg-accent`, `text-muted`, `border-line`. All solid — **don't fade things with opacity / `white/xx`** (minimal ≠ faint). The default Tailwind palette is disabled on purpose. Layout vars: `--frame-width`, `--frame-inset`, `--frame-gutter`, `--nav-top`, `--nav-clearance`. Navbar type uses the `nav-text` utility.
- **Typography** (`src/styles/typography.css`): `font-display` = Old English Text MT (major headings; `h1–h3` default to it), `font-body` = Imbue (everything else, loaded from Google Fonts in `index.html`). Fluid sizes: `text-display-xl|lg|md`, `text-body-lg`.
- **React Bits**: add individual components only when a section needs them. `components.json` exists only so the registry CLI works — no shadcn/ui is installed:
  `npx shadcn@latest add https://reactbits.dev/r/<Name>-TS-TW -p src/components/effects/<Name> --yes`
  **Always diff the result against the registry JSON** (`https://reactbits.dev/r/<Name>-TS-TW.json`): the CLI's transform has corrupted files before (SVG matrices, rgba colours). Vendored React Bits folders are excluded from oxlint.
  - `effects/GradualBlur` (React Bits) — bottom-edge blur band for the Story content reveal. Mount it only when needed; never mount it hidden (Chromium leaves masked backdrop layers that mount while invisible un-rendered).
- **Hero → Story transition** (`sections/Story`): Story opens with a full-viewport transition stage pulled up *under* the Hero (`motion-safe:-mt-[100svh]`) and pinned from the first pixel of scroll for 2.2 viewport heights; its background starts as the Hero's warm white and the transparent Hero slides away over it. One scrubbed timeline: a warm dome (`.transition-glow`, modelled on pixelate.one's bottom-anchored glow) rises and spreads, its red core floods the viewport, black takes over, then the star and title reveal; it reverses on scroll up. In-page navigation to Story lands after the transition via `[data-section-anchor]` (`useScrollToSection`). Every other section keeps the page's black. Navbar/frame tone and the frame matte follow the transition progress via `lib/chromeTone.ts` (forced dark until the Loader starts opening, or while the menu covers the page — `hooks/useChromeTone`). Reduced motion: no overlap, no pin — the Hero has its own canvas and the stage is black.
- **Cursor**: `effects/FluidCursor` (custom) — the live page is a fluid surface the pointer stirs. The flow is a real fluid: `fluidField.ts`, a small CPU stable-fluids solver (advection, a short Jacobi pressure solve, vorticity confinement, dissipation) on a 16px grid, stepped only over the disturbed window and only while it moves. A lagged stirring point (the inertia) pushes its own velocity along its path — push-only, so a slowing pointer leaves the wake to coast and settle (~1s). The page is displaced by the browser, not WebGL (WebGL cannot read DOM pixels): each frame the flow is encoded as a small displacement PNG (8px per pixel; bilinear-upsampled flow + soft floor/cap + a fine noise ripple, all on the CPU), pre-decoded, and fed through `<feImage>` into an SVG filter applied as `backdrop-filter`, which samples the live backdrop three times (R/G/B at ±8% strength) and blends each channel 60/40 with the centre sample (an edge bleed; small text stays legible). **Performance rule (measured on Iris Xe):** every filter primitive is a full-resolution GPU pass, and Chromium evaluates the filter as a tree — anything read by the three samples runs three times. An in-filter blur + `feTurbulence` ripple shared by the samples cut pointer-motion frame rates to ~30fps; now each sample reads its own `<feImage>` and nothing else is shared (60fps). Keep blur/noise/extra primitives out of the filter — do that work in the map. A decode generation counter keeps a stale map from re-enabling the filter after a stop/resize. Filter region = disturbed area only; removed entirely at rest. Paused while the menu is open (`paused` prop from AppShell). Layered at z-44 — above content, below the navbar (z-45) and frame (z-50), which therefore stay crisp: keep that order. Chromium + fine pointer + motion allowed only. Tuning constants live at the top of the file.
- **Intro**: `layout/Loader`, modelled on ryanritzenthaler.com's loader — black screen, a small rolling 3-column counter (motion-blurred while it rolls) over a thin bar at the centre, both following real readiness (fonts, window load; never faster than 0.8s, 3.5s cap). At 100 the counter fades and the bar retracts to its right end; then one black curtain shrinks to 0.8 and its bottom edge lifts away (1s, `power4.inOut`), a crimson layer beneath trailing the lift by 25ms (the accent line on the rising edge). `markIntroReady()` (`lib/intro.ts`) fires as the counter goes out — nav + Hero hide and wait `INTRO_HANDOFF` (1.3s), timed so the Hero's name starts rising as the curtain's edge clears the centre; `markIntroOpen()` just after the curtain starts moving releases the chrome tone. Reduced motion: static count until ready (≤1.2s), short fade, no entrance. `index.html` paints the page black before any CSS/JS.
- **Story title**: star and title share the stage centre; `sections/Story/useCenteredTitle` adds only ink-based optical correction to the flex-centred lines (shared helper: `lib/ink.ts`).
- **Hero name**: `sections/Hero/useOpticalName` measures real glyph ink (canvas TextMetrics) to give both lines the same visible left edge and centre the visible ink in the panel. Never put a CSS `translate` on an element GSAP animates — GSAP folds it into its transform (the block is placed with left/top for that reason).

## Assets

- `public/assets/{images,fonts,models}` — served as-is by URL (e.g. `/assets/models/star.glb`).
- `src/assets/{images,models,fonts}` — imported from code and bundled/hashed by Vite.
- **Old English Text MT** is a commercial font. It currently resolves from the visitor's installed copy; for production, place a licensed web file at `public/assets/fonts/old-english-text-mt.woff2`. (The build warns about this path until the file exists — expected.)

## Status

**Placeholders:** Midnight Labs, Skills, Contact, Footer.
- **Featured Work** (`sections/Projects`): horizontal showcase — the section pins and vertical scroll drives the track sideways (scrubbed, `PACE` × travel), md+ with motion only; phones / reduced motion stack vertically. Intro, then one editorial spread per project: preview (uncovered left → right, settling from a slight zoom; anchored top-left so crops fall on the right) beside the title in the display face, a crimson hairline, the meta line, description, highlights and stack; the credit (e.g. a placing) in crimson. Reveals follow the track (see Scroll reveals). Data in `projectData.ts` (facts from the READMEs and the résumé); PeerSpace has no screenshot yet, so a typographic placeholder stands in. No blur on the previews.

- **Star silhouette** comes from `src/lib/star.ts`: a regular six-point star (inner/outer radius 0.382) measured from `public/assets/images/main-star.png` (99.7% pixel IoU). The WebGL star (`effects/CrystalStar`) and the SVG nav mark (`navigation/StarMark`) are both generated from it — never swap in a generic star.
- **Page rhythm**: Hero ≈ one viewport; everything else is content-driven. Only pin a section when it genuinely needs it (e.g. horizontal Featured Work). Story pins for its Hero → Story transition (see above); the star reads GSAP-written values from a ref (`StarMotion`) inside `useFrame`. The star's canvas renders only while its stage is in view *and* the transition has reached its reveal (`STAR_LIVE_AT`) — the stage sits under the Hero, so in-view alone kept an invisible canvas redrawing every frame. Reduced motion: `frameloop="demand"`. `WebGLCanvas` has an error boundary: no WebGL → the consumer's `fallback` (the star PNG), never a crashed page.
- **UI * UX * Stunning** (`sections/Statement`) is a compact marquee band closing Story, built on `effects/VelocityMarquee` (Lenis velocity: faster on scroll down, reverses on scroll up).
- **Menu**: `navigation/MenuOverlay` is an interim stand-in for the React Bits StaggeredMenu — keep its id/open/close/focus contract when replacing it.
- **Portrait**: set `PORTRAIT_SRC` in `sections/Story/StoryContent.tsx` once the photo is in `public/assets/images/`.
